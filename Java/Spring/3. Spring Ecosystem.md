# 3. Spring Ecosystem Beyond the Core

After Spring solved object management, the team extended the same philosophy to every enterprise concern. Each project integrates seamlessly with the IoC container.

## Spring MVC / WebFlux — Web Layer

Spring MVC provides a Servlet-based, synchronous web framework. Spring WebFlux (added Spring 5) adds reactive, non-blocking web with Project Reactor. Same annotations (`@Controller`, `@RequestMapping`), different runtime model.

## Spring Data — Data Access

Abstracts CRUD repositories. Write an interface, Spring generates the implementation. Supports JPA, MongoDB, Redis, Cassandra, JDBC, R2DBC. Key: `JpaRepository<Entity, ID>`.

## Spring Security — Auth & Authz

Pluggable authentication (form login, OAuth2, JWT, LDAP) and method/URL-level authorization. Integrates as a filter chain around your app — zero intrusion into business logic.

## Spring Cloud — Microservices

Service discovery (Eureka), config server, API gateway (Spring Cloud Gateway), circuit breakers (Resilience4j), distributed tracing (Micrometer + Zipkin). Entire microservice toolkit on Spring idioms.

## Spring Batch / Spring Integration

- **Batch:** Process large data sets with chunk-oriented processing, retry, skip, parallel steps.
- **Integration:** Enterprise messaging patterns (EIP) — routes, transformers, channels — for connecting heterogeneous systems.

## Spring AOP — Cross-cutting Concerns

Aspect-Oriented Programming baked in. Use `@Transactional`, `@Cacheable`, `@Async`, or write custom `@Aspect` for logging, auditing, rate-limiting — all applied transparently via proxies.
